# Codex 能力控制中心

让 Codex 的规则、Skill 和 AI 技巧不再“装完就忘、变了不知道、好坏凭感觉”。

这是一个本地优先的能力维护工具：发现变化，核对证据，由你决定，再验证真实结果。每个待办都回答四件事——为什么出现、系统建议什么、你能做什么、做完以后怎样确认。

**[立即体验公开演示](https://suijie.github.io/codex-skill-atlas/)**

![Codex 能力控制中心预览](preview.jpg)

## 它解决什么问题

- **规则会不会过时？** 标出真正变化的段落，解释影响，复核后留下当前版本记录。
- **Skill 到底能不能用？** 区分文件完整、实际试用、内容变化和近期使用，不用模糊的“可能可用”。
- **新能力值不值得装？** 同时核对来源、维护状态、公开热度、结构、安全和角色适配，不按 Star 盲目推荐。
- **AI 技巧质量如何判断？** 只收录身份明确的一手来源、可验证正文、正反示例和具体行动，并识别与现有规则的重复。
- **检查完以后呢？** 批准、安装、文件检查和完成结果留在当前上下文，扫描与运行都可以追溯。

## 当前产品结构

五个一级入口对应五种清楚的用户任务：

1. **总览**：只看待处理、核心状态和值得关注。
2. **维护中心**：判断建议，查看每周复盘和扫描结果。
3. **规则文件**：复核被明确标色的变化。
4. **Skill 能力库**：查看中文说明、质量状态、近 30 天使用和维护动作。
5. **AI 技巧**：按需浏览可信方法，不把信息推荐变成待办。

安装、检查与试用、活动与差异、备份恢复、环境检查是二级维护工具，不额外占用主导航。

## 公开演示可以体验什么

- 连续完成规则复核
- 查看一条 Skill 推荐的来源、热度、适用场景和风险
- 在原卡片内完成批准、安装进度与文件检查
- 搜索和筛选 Skill，查看中文用途、近期调用和删除确认
- 浏览、收藏或标记已掌握的 AI 技巧
- 用全局搜索快速前往页面与功能
- 在桌面与手机上使用完整导航和关键流程

公开页面使用虚构、脱敏的数据。所有操作只改变当前网页状态，不读取或修改访客设备。

## 推荐与判断原则

- 允许没有新推荐，不为数量降低门槛。
- 单次观察不会进入长期规则；重复模式才进入评估。
- GitHub 热度只是一项证据，不等于质量。
- 文件检查通过不等于真实任务效果，二者分别记录。
- 旧结果只对当时的文件版本有效，内容变化后必须重新验证。
- 任何规则修改、Skill 安装或删除都需要用户明确确认。

## 隐私与项目边界

- 公开仓库不包含个人规则、真实 Skill 内容、使用记录、本机路径、账号信息或本地管理服务。
- 演示页面不使用网络采集接口，不上传搜索、筛选或交互记录。
- 完整产品在用户本机运行；这个仓库展示产品定位、信息架构和关键交互，并不是远程管理服务。
- 本项目为非官方个人项目，与 OpenAI 不存在隶属或背书关系。Codex 与 OpenAI 是其各自权利人的商标。
