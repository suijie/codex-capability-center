# Codex Skill Atlas｜中文能力图谱

别再盲目安装 Skill。这里用中文回答三个更重要的问题：它能解决什么任务、什么时候不该用、多个 Skill 应该如何组合。

## 为什么值得收藏

- 30 项精选 Codex Skill，覆盖产品研究、界面设计与实现、文档表格、内容创作、浏览器和 GitHub 协作
- 7 条任务路径，不只列工具，还说明推荐组合和使用顺序
- 每项都有中文说明、适用/不适用边界、典型输入输出和示例任务
- 持续补充新能力并淘汰过时信息；没有可靠证据时，不为了更新而更新

**[在线体验](https://suijie.github.io/codex-skill-atlas/)** · 如果这份整理帮你少走了弯路，欢迎点一个 Star，方便以后回来查看。

![Codex Skill Atlas 中文能力图谱预览](preview.jpg)

## 你可以怎么用

1. 不知道该用哪个 Skill：直接搜索你的任务，例如“做产品原型”“处理 PDF”“修复 CI”。
2. 需要多个能力协作：打开“使用场景”，查看从研究、设计到交付的推荐顺序。
3. 容易选错：查看每项能力的“不适用场景”，或者阅读能力对比。

## 当前内容

- 版本：Public V2.0
- 最近整理：2026-09-03
- 30 项能力、7 个分类、7 条任务路径
- 搜索、筛选、排序、收藏和详情深链接

`index.html` 是可直接部署的单文件站点；`manifest.json` 记录本次发布物的 SHA-256 摘要。收藏仅保存在当前浏览器，本页面不主动上传收藏、搜索或使用记录；静态托管服务仍可能按其政策保留基础访问日志。

## 隐私和项目边界

- 公开版不包含本机路径、内部任务 ID、个人规则或账号信息
- 不读取、安装、更新或控制访客的 Codex
- 非 OpenAI 官方产品；实际能力与可用性以当前 Codex 版本和官方资料为准

发现内容过时、表述错误或能力缺失时，欢迎[提交 Issue](https://github.com/suijie/codex-skill-atlas/issues)。
