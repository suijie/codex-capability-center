关于

少装错，比装得多更重要

这是一份持续维护的 Codex Skill 中文能力图谱：帮助使用者理解边界、组合能力，也公开我们的选择方法。

隐私边界

公开页面不包含本机路径、内部任务 ID、个人规则原文、账号信息或项目标识，也不会读取访客的 Codex 数据。

内容边界

页面只提供能力摘要、选择建议与维护方法，不转载各 Skill 的完整内部说明。具体行为以当前安装版本为准。

数据保存

收藏只保存在当前浏览器本地；页面不主动上传收藏、搜索或使用记录。静态托管服务仍可能按其政策保留基础访问日志。清除浏览器站点数据后，收藏会被移除。

品牌说明

Codex 与 OpenAI 是其各自权利人的商标。本项目为非官方个人示例，与 OpenAI 不存在隶属或背书关系。
